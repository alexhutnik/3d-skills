# Design decorative printed parts

Use exact extruded outlines for lettering, keychains, badges, and layered designs with controlled dimensions.
Use mesh or sculpting tools when the form needs organic surfaces.
Check the local tool before promising a sculpted deliverable.

For vector input, confirm the units, scale, closed contours, holes, and duplicate paths.
Treat an image trace as an approximation. Inspect small features at the intended physical size.
Keep letter counters open. Connect intended islands or export them as explicitly separate parts.
Check narrow links near the keyring hole and between letters.
Do not use an unscaled screen preview to judge printable stroke thickness.

For layered colors, choose the base plane and thickness of each layer.
Use shared boundaries or an explicit overlap that the slicer can handle.
Do not silently add a gap between colors.
Keep physical part exports separate from display materials.
Verify color assignments and layer heights in the slicer before printing.

Expose overall scale, base thickness, relief height, hole size, and the smallest intended feature.
Make a crop coupon when small lettering or a new material determines the result.
Use `../inspect-3d/SKILL.md` for a browser view with clear part colors.
Use `../release-3d-print/SKILL.md` to check solids, separate islands, and printable features.
